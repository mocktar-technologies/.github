### Open source

**[eslint-config-vibe-safe](https://github.com/mocktar-technologies/eslint-config-vibe-safe)**
ESLint rules for the authorization and configuration mistakes AI coding
assistants make in Next.js and Supabase code. Catches what passes a type check
and is still wrong. Zero dependencies, 46 tests.

**[vibe-to-production-kit](https://github.com/mocktar-technologies/vibe-to-production-kit)**
A Next.js and Supabase starter with the production gates already wired:
validated environment, verified auth, secret scanning, and a CI pipeline that
fails on the defects a type check does not see.

### Free tools

Both run entirely in your browser. Nothing is uploaded.

**[Pinhole](https://mocktar.com/tools/pinhole/)** grades a GitHub Actions
workflow against fourteen supply chain and permission checks, and names the line
to fix.

**[Deadpanel](https://mocktar.com/tools/deadpanel/)** finds Grafana panels
querying metrics your Prometheus setup no longer exposes, so you learn about the
blind spot before an incident does.
